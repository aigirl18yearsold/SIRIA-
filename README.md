SIRIA 🔵

Digital Solutions for Modern Business

SIRIA is a modern and professional business website template designed for online service providers, digital agencies, startups, freelancers, and growing businesses.

Built with a clean radiant blue visual identity, SIRIA focuses on modern design, responsiveness, and a professional user experience.

---

✨ Features

- 🔵 Modern radiant blue design
- 📱 Fully responsive layout
- 🚀 Professional landing page
- 💼 Services section
- 📊 Business statistics section
- 👥 About and features section
- 🔄 Simple four-step process section
- ⭐ Client testimonials
- 💰 Pricing plans
- 📩 Contact section
- 🌙 Premium dark user interface
- 📱 Mobile-friendly navigation
- ⚡ Fast and lightweight
- 🎨 Built with pure HTML, CSS, and JavaScript

---

🛠️ Built With

- HTML5
- CSS3
- JavaScript

No frameworks or external libraries are required.

---

🌐 Deploy with GitHub Pages

You can easily host this website for free using GitHub Pages.

1. Upload the project files to a GitHub repository.
2. Go to the repository Settings.
3. Select Pages.
4. Under Build and deployment, select:

Deploy from a branch

5. Choose:

Branch: main
Folder: / (root)

6. Save your settings.

Your website will then be published through GitHub Pages.

🎨 Customization

You can easily customize the website by editing:

- Brand name
- Colors
- Services
- Pricing
- Testimonials
- Contact information
- Business statistics
- Text content

The main color variables are located near the top of the CSS:

:root {
  --primary: #1479ff;
  --primary-dark: #0756d8;
  --primary-light: #52a5ff;
  --dark: #061426;
}

Change these values to create your own brand identity.
